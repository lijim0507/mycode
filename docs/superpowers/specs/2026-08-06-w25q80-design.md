# W25Q80 SPI NOR Flash 驱动库 — 设计规格

**日期**: 2026-08-06
**状态**: 待用户评审

---

## 1. 概述

为 Winbond W25Q80（8 Mbit / 1 MB SPI NOR Flash）提供一个完整的、可复用的嵌入式驱动模块，遵循项目的三层架构规范。

### 决策汇总

| 维度 | 决定 |
|---|---|
| 功能范围 | 完整：Read/FastRead/PageProgram/SectorErase/BlockErase/ChipErase/RDID/UniqueID/StatusReg/PowerDown |
| SPI 传输 | 块传输 driver 注入（`spi_write` / `spi_read` / `spi_transceive`） |
| 实例模型 | 单例（`g_driver` + `g_initialized`） |
| 目标平台 | ESP32（ESP-IDF `spi_master`）+ STM32（HAL SPI） |

## 3. Port Driver 接口

### `w25q80_port_driver_t`（定义于 `port/w25q80_port.h`）

```c
typedef struct
{
    int  (*init)(void);
    int  (*deinit)(void);
    void (*cs_set)(uint8_t level);
    int  (*spi_write)(const uint8_t *data, uint16_t len);
    int  (*spi_read)(uint8_t *data, uint16_t len);
    int  (*spi_transceive)(const uint8_t *tx, uint8_t *rx, uint16_t len);
    void (*delay_us)(uint32_t us);
    void (*delay_ms)(uint32_t ms);
} w25q80_port_driver_t;

const w25q80_port_driver_t *w25q80_port_get_driver(void);
```

| 函数 | 职责 |
|---|---|
| `init` | 初始化 SPI 外设 + CS GPIO，签名 `int (*)(void)`（无 config 参数） |
| `deinit` | 释放 SPI 资源和 GPIO |
| `cs_set(level)` | CS 引脚控制（0 = 选中, 1 = 释放） |
| `spi_write(buf, len)` | 只发不收，MOSI 发送数据，忽略 MISO |
| `spi_read(buf, len)` | 只收不发，MOSI 发 `0xFF`，MISO 接收数据 |
| `spi_transceive(tx, rx, len)` | 全双工，同时发送和接收 |
| `delay_us(us)` | 微秒延时 |
| `delay_ms(ms)` | 毫秒延时 |

### Port 自封装规则

- `init()` 不接受任何配置参数
- 所有硬件参数（SPI 主机号、CS GPIO、时钟频率）通过文件内 `#ifndef` 宏定义，用户可通过编译选项覆盖
- Core 层在 `w25q80_init()` 内部调用 `w25q80_port_get_driver()` 获取 port driver

## 4. 公开 API（`include/w25q80.h`）

### 类型定义

```c
typedef struct
{
    uint8_t  manufacturer_id;   /* 0xEF = Winbond */
    uint8_t  memory_type;       /* 0x13 = W25Q80 */
    uint8_t  capacity;          /* 0x14 = 8 Mbit */
    uint8_t  unique_id[8];      /* 64-bit unique ID */
} w25q80_info_t;

typedef struct
{
    uint32_t  read_timeout_ms;  /* 默认 1000ms，擦除/写入轮询 BUSY 超时 */
} w25q80_config_t;

typedef struct
{
    uint8_t  sr1;   /* BUSY(0), WEL(1), BP0(2), BP1(3), BP2(4), TB(5), SEC(6), SRP0(7) */
    uint8_t  sr2;   /* SRP1(0), CMP(6), QE(1), LB[3:1](3:5), SRP1(7) */
    uint8_t  sr3;   /* WPS(2), DRV[1:0](6:7) */
} w25q80_status_t;
```

### API 列表

| 函数 | 说明 |
|---|---|
| `w25q80_init(config)` | 初始化模块，config 可为 NULL 使用默认值 |
| `w25q80_deinit()` | 反初始化 |
| `w25q80_read_jedec_id(info)` | 读 JEDEC ID（制造商+型号+容量） |
| `w25q80_read_unique_id(uid)` | 读 64-bit unique ID（8 字节 out buffer） |
| `w25q80_read(addr, data, size)` | 普通读（opcode `0x03`，无 dummy，≤40MHz） |
| `w25q80_fast_read(addr, data, size)` | 快速读（opcode `0x0B`，1 dummy byte，≤80MHz） |
| `w25q80_write(addr, data, size)` | 写数据，自动 WREN + 跨页拆分 + 轮询 BUSY |
| `w25q80_sector_erase(addr)` | 4KB 扇区擦除 |
| `w25q80_block32_erase(addr)` | 32KB 块擦除 |
| `w25q80_block64_erase(addr)` | 64KB 块擦除 |
| `w25q80_chip_erase()` | 整片擦除 |
| `w25q80_read_status(status)` | 读全部 3 个状态寄存器 |
| `w25q80_write_status(sr1, sr2, sr3)` | 写状态寄存器（自动 WREN + 轮询 BUSY） |
| `w25q80_write_enable()` | 发送 WREN（`0x06`），每步写/擦前必须调用 |
| `w25q80_write_disable()` | 发送 WRDI（`0x04`） |
| `w25q80_is_busy()` | 返回非 0 表示芯片正在擦/写（内部轮询 SR1 BUSY 位） |
| `w25q80_power_down()` | 进入掉电模式（`0xB9`），电流降至 ~1µA |
| `w25q80_release_power_down()` | 退出掉电模式（`0xAB`），等待 3µs 后恢复正常 |

### 返回值约定

| 返回值 | 含义 |
|---|---|
| `0` | 成功 |
| `-1` | 参数错误（空指针、地址越界、长度为零） |
| `-2` | 未初始化 |
| `-3` | 超时（擦/写等待 BUSY 超时） |
| `-4` | Port driver 无效（`init` 时 port driver 指针/函数指针为 NULL） |

## 5. Core 层设计

### 内部状态

```c
static const w25q80_port_driver_t *g_driver;
static bool                         g_initialized;
static w25q80_config_t              g_config;
```

### SPI 命令格式（W25Q80 数据手册摘要）

| 操作 | Opcode | 地址 | Dummy | 数据 | 备注 |
|---|---|---|---|---|---|
| Write Enable | `0x06` | — | — | — | |
| Write Disable | `0x04` | — | — | — | |
| Read Status Reg 1 | `0x05` | — | — | 1 B | |
| Read Status Reg 2 | `0x35` | — | — | 1 B | |
| Read Status Reg 3 | `0x15` | — | — | 1 B | |
| Write Status Reg | `0x01` | — | — | 1-3 B | |
| Read Data | `0x03` | 3 B | — | N B | |
| Fast Read | `0x0B` | 3 B | 1 B | N B | |
| Page Program | `0x02` | 3 B | — | ≤256 B | 不可跨页 |
| Sector Erase 4KB | `0x20` | 3 B | — | — | |
| Block Erase 32KB | `0x52` | 3 B | — | — | |
| Block Erase 64KB | `0xD8` | 3 B | — | — | |
| Chip Erase | `0xC7` / `0x60` | — | — | — | |
| Read JEDEC ID | `0x9F` | — | — | 3 B | 不需发地址 |
| Read Unique ID | `0x4B` | — | 4 dummy | 8 B | 先发 4 个 dummy |
| Power Down | `0xB9` | — | — | — | |
| Release PD | `0xAB` | — | — | — | 后续需 3µs 唤醒时间 |

### 关键数据流

**写操作流程：**
```
w25q80_write(addr, data, size):
  校验参数 → 遍历按 256 字节页拆分
    每个 chunk:
      WREN → CS low → 0x02 + 3B地址 + chunk数据 → CS high
      → 轮询 RDSR BUSY 位直到清零或超时
```

**读操作流程：**
```
w25q80_read(addr, data, size):
  校验参数 → CS low → 0x03 + 3B地址 → 读 N 字节 → CS high
```

**擦除操作流程：**
```
w25q80_sector_erase(addr):
  WREN → CS low → 0x20 + 3B地址 → CS high → 轮询 BUSY 直到清零或超时
```

### 边界处理

- 地址 + size 不可超过 `W25Q80_CAPACITY`（1,048,576 字节）
- Page Program 每次不超过 256 字节，且不可跨页
- 擦除地址必须按扇区/块大小对齐（Core 层校验或由调用方保证？→ **Core 层校验**：传入地址自动按擦除单位对齐掩码，拒绝未对齐地址返回 -1）
- 写/擦除前必须 WREN，操作完成后 WEL 自动清零

## 9. 专项设计决策

### 擦除地址对齐

Core 层在 `sector_erase()`、`block32_erase()`、`block64_erase()` 中校验地址对齐：
- Sector Erase: `address % 4096 == 0`，否则返回 `-1`
- Block Erase 32KB: `address % 32768 == 0`，否则返回 `-1`
- Block Erase 64KB: `address % 65536 == 0`，否则返回 `-1`

### 写操作的 WREN 策略

`w25q80_write()` 内部自动对每个 page chunk 调 WREN（因为 WEL 在每次 Page Program 完成后自动清零）。调用方无需手动 WREN。

擦除函数同理，内部自动 WREN。

### Fast Read 的 SPI 频率

Fast Read (`0x0B`) 支持最高 80MHz 时钟。但 config 中的 `clk_speed` 是在 port 内部设置的全局值。Fast Read 时 core 层无法动态切换频率。**决定**：core 层不做频率切换，用户如果在 `W25Q80_ESP32_CLK_SPEED` 中配置了 40MHz（默认值），Fast Read 以 40MHz 运行也能正常工作（仅不发挥 80MHz 优势）。如需更高速度，用户可自行提高宏值。

### 状态寄存器写保护的完整支持

3 字节状态寄存器一次性写入。BP0-BP2、CMP、SEC、TB、SRP0/SRP1 位的含义在 public header 中以宏形式暴露（如 `W25Q80_SR1_BP0` 等），方便上层位操作。
